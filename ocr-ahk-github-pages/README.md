# OCR.ahk Documentation

GitHub Pages documentation for **OCR.ahk v2.0.0**, an AutoHotkey v2 wrapper around Windows `Windows.Media.Ocr`.

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and the `assets/` directory.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your default branch and `/ (root)`.
6. Save.

GitHub will publish the site at the repository's Pages URL.

## Files

- `index.html` — documentation site
- `assets/style.css` — site styling
- `assets/script.js` — smooth navigation

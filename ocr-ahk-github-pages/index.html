AutoHotkey v2 · Windows OCR

OCR.ahk

A native AutoHotkey v2 wrapper around Windows.Media.Ocr with screen, window, image, bitmap, and PDF OCR plus structured results and interaction helpers.

01

Getting Started

Install the file, include it, then call one of the OCR source methods.

Requirements

  • Windows
  • AutoHotkey v2
  • A Windows language component with OCR support for the language you want to recognize

Languages use BCP-47 language tags such as en-us and en-AU.

Minimal example

#Requires AutoHotkey v2
#Include OCR.ahk

result := OCR.FromDesktop()
MsgBox result.Text
02

OCR Sources

Choose the source that matches what you need to recognize.

OCR.FromDesktop

OCR.FromDesktop(Options?)

Captures the desktop and returns an OCR.Result.

result := OCR.FromDesktop()
MsgBox result.Text

OCR.FromMonitor

OCR.FromMonitor(Monitor?, Options?)

OCRs a specific monitor. The monitor can also be supplied through options.

result := OCR.FromMonitor(2, {lang: "en-us"})

OCR.FromRect

OCR.FromRect(X, Y, W, H, Options?)

OCRs a rectangular screen area.

result := OCR.FromRect(100, 100, 800, 400, {scale: 2})
MsgBox result.Text

OCR.FromWindow

OCR.FromWindow(WinTitle := "", Options?, WinText := "", ExcludeTitle := "", ExcludeText := "")

Captures a window. Result coordinates follow the A_CoordModePixel mode used during capture.

modeCapture method
0GetDC + BitBlt
1BitBlt with transparency disabled
2PrintWindow
3PrintWindow with transparency disabled
4PrintWindow + PW_RENDERFULLCONTENT
5Direct3D 11 / Windows.Graphics.Capture
result := OCR.FromWindow("My Application", {mode: 4})
MsgBox result.Text

Mode 5 is the slowest option but may work with games and other applications that are difficult to capture normally.

OCR.FromFile

OCR.FromFile(FileName, Options?)

OCRs an image file. Locations are relative to the top-left of the image.

result := OCR.FromFile("image.png", {lang: "en-us"})
MsgBox result.Text

Supported decoder names: gif, ico, jpeg, jpegxr, png, tiff, bmp.

OCR.FromBitmap

OCR.FromBitmap(bitmap, Options?, hDC?)

OCRs a bitmap object, GDI+ bitmap pointer, HBITMAP, or compatible object containing a pointer.

result := OCR.FromBitmap(bitmap)
MsgBox result.Text

OCR.Call

OCR(RandomAccessStreamOrSoftwareBitmap, Options?)

The main low-level entry point. Use it when you already have a Windows Runtime IRandomAccessStream or SoftwareBitmap.

03

Image Options

Options can be passed to OCR source methods as an object.

OptionPurposeExample
lang / languageOCR language. Can also be a function returning a language.{lang: "en-us"}
scaleScales the image before OCR.{scale: 2}
grayscaleConverts the image to grayscale.{grayscale: true}
monochrome0–255 luminance threshold; pixels below it become black and others white.{monochrome: 128}
invertcolorsInverts image colors.{invertcolors: true}
rotateClockwise rotation.{rotate: 90}
flipFlip on the x or y axis.{flip: "x"}
x,y,w,hCrop before scaling.{x: 100, y: 50, w: 500, h: 200}
decoderExplicit image decoder.{decoder: "png"}

Combining options

result := OCR.FromDesktop({
    lang: "en-us",
    scale: 2,
    grayscale: true,
    rotate: 0
})
04

OCR Results

OCR returns structured objects instead of only a text string.

OCR.Result

PropertyDescription
TextAll recognized text.
TextAngleClockwise rotation of recognized text.
LinesArray of OCR.Line objects.
WordsArray of OCR.Word objects.
ImageWidthWidth of the image used for OCR.
ImageHeightHeight of the image used for OCR.
for word in result.Words {
    MsgBox word.Text
}

Lines and Words

OCR.Line provides Text, Words, and x,y,w,h.

OCR.Word provides Text, x,y,w,h, and BoundingRect.

for line in result.Lines
    MsgBox line.Text

for word in result.Words
    MsgBox word.Text " @ " word.x "," word.y
05

Searching Text

Turn OCR output into something your script can act on.

FindString

Result.FindString(Needle, Options?)

Finds a string and returns an OCR result containing the matching words.

OptionDescription
CaseSenseCase-sensitive matching.
IgnoreLinebreaksTreats line breaks as spaces.
AllowOverlapAllows overlapping matches.
iOccurrence to return.
x,y,w,hRestricts the search area.
SearchFuncCustom search function.
match := result.FindString("Confirm")
match.Highlight()
match.Click()

FindStrings

Result.FindStrings(Needle, Options?)

Returns all matching occurrences.

for match in result.FindStrings("Error")
    match.Highlight()
06

Filter & Crop

Reduce a result to only the words or region you need.

Filter

Result.Filter(callback)

Returns a result containing only words accepted by the callback.

filtered := result.Filter((word) => StrLen(word.Text) > 3)

Crop

Result.Crop(x1, y1, x2, y2)

Creates a result containing OCR objects inside the rectangle defined by two points.

cropped := result.Crop(100, 100, 600, 400)
07

Interaction

OCR objects can be highlighted or used as mouse/control targets.

Highlight

Result.Highlight(showTime?, color := "Red", d := 2)

Highlights an OCR object. The same method works for results, lines, words, and compatible objects containing x,y,w,h.

word.Highlight()          ; default: 2 seconds
word.Highlight(0)        ; keep visible
word.Highlight(-2000)    ; non-blocking timer
word.Highlight("clear")  ; clear this highlight
OCR.ClearAllHighlights() ; clear all

Click

Result.Click(WhichButton?, ClickCount?, DownOrUp?)

Clicks the center of the OCR object's bounding rectangle. Window-relative information from FromWindow is respected.

result.FindString("Start").Click()

ControlClick

Result.ControlClick(WinTitle?, WinText?, WhichButton?, ClickCount?, Options?, ExcludeTitle?, ExcludeText?)

Performs AutoHotkey ControlClick using the object's coordinates. A suitable window context or WinTitle is required.

OffsetCoordinates

Result.OffsetCoordinates(offsetX?, offsetY?)

Moves every word's coordinates by an offset. When omitted, offsets can be taken from the result's Relative property.

08

PDF OCR

Render and recognize individual pages or ranges of a PDF.

FromPDF

OCR.FromPDF(FileName, Options?, Start := 1, End?, Password := "")

Returns an array of OCR results, one for each processed page.

pages := OCR.FromPDF("document.pdf")

for page in pages
    MsgBox page.Text

FromPDFPage

OCR.FromPDFPage(FileName, Page, Options?, Password := "")

OCRs one page. Page numbers are one-based.

page := OCR.FromPDFPage("document.pdf", 3)
MsgBox page.Text

PDF Helpers

OCR.GetPdfPageCount(FileName, Password := "")
OCR.GetPdfPageProperties(FileName, Page, Password := "")

GetPdfPageProperties returns {Width, Height, Rotation, PreferredZoom}.

09

Languages

Use Windows OCR language support through BCP-47 language tags.

Get available languages

MsgBox OCR.GetAvailableLanguages()

Load a language

OCR.LoadLanguage("en-us")

The default language is the first available OCR language. Not every Windows language pack provides OCR support.

10

WaitText

Repeatedly call an OCR method until a target string is found.

OCR.WaitText

OCR.WaitText(needle, timeout := -1, func?, casesense := False, comparefunc?)
result := OCR.WaitText("Ready", 10000)

if IsSet(result)
    MsgBox "Ready detected!"

By default the provided OCR method is used repeatedly. A custom function can be supplied for a particular screen region or source.

result := OCR.WaitText(
    "Ready",
    10000,
    () => OCR.FromRect(400, 300, 500, 200)
)
11

Clustering

Group OCR objects by position using the library's clustering helper.

OCR.Cluster

OCR.Cluster(objs, eps_x := -1, eps_y := -1, minPts := 1, compareFunc?, &noise?)

Clusters objects based on distance. It can be used to create more accurate line-like groups from OCR words.

clusters := OCR.Cluster(result.Words)

for cluster in clusters
    MsgBox cluster.Text

Cluster objects contain position, size, combined text, and their grouped words.

12

Array Utilities

Small helpers included with the library.

OCR.SortArray(arr, optionsOrCallback := "N", key?) — sorts an array in-place.

OCR.ReverseArray(arr) — reverses an array in-place.

OCR.UniqueArray(arr) — returns an array containing unique values.

OCR.FlattenArray(arr) — converts a multidimensional array into one dimension.

15

Errors & Limitations

Handle normal AutoHotkey exceptions around OCR operations.

try {
    result := OCR.FromFile("image.png")
    MsgBox result.Text
} catch Error as err {
    MsgBox "OCR failed:`n" err.Message
}
  • Target windows that cannot be found cause an error.
  • Missing image files cause an error.
  • Images exceeding the Windows OCR maximum dimension are rejected.
  • Requested languages must have OCR support installed.
  • Window capture behavior varies by application; try another mode when necessary.
  • Small images may be scaled automatically; the library notes an apparent minimum of about 40 pixels.
